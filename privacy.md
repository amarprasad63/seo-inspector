# Privacy Policy for SEO Inspector

Last updated: October 21, 2026

## Overview

SEO Inspector is a browser extension that helps users inspect webpages for SEO issues, structured data, social metadata, technical issues, and supported accessibility signals.

## Information Collection and Use

SEO Inspector processes webpage content, including metadata, headings, links, images, and structured data, to perform audits requested by the user.

The extension is designed to perform its analysis locally in the browser. It does not intentionally transmit inspected webpage content to an external server, collect personal information, or sell user data, provided the installed version operates as described.

The extension uses Chrome's local extension storage only for these settings on this device:

- The light or dark background choice.
- The primary keyword, secondary keywords, and brand, and only after you check **Remember on this device**. Unchecking that box deletes the saved keywords.

Audit results are not saved in extension storage.

If you choose **Show preview image**, your browser requests that image address so it can display the picture. The extension does not upload the audit with that request.

## Data Sharing

SEO Inspector does not sell user data or share inspected webpage content with third parties for advertising.

## Data Retention and Security

Audit processing is intended to occur locally in the browser. Data stored by the extension, if any, is subject to the browser's extension storage and user-controlled settings. You can remove the saved settings by changing them in the extension or by removing the extension.

## Permissions

The extension requests browser permissions needed to inspect webpages, execute its packaged inspection logic, display results in the popup and side panel, and maintain necessary extension state.

## Changes to This Policy

This policy may be updated if the extension's functionality or data practices change. Updates will be published on this page.

## Contact

For questions about this privacy policy, please contact the extension publisher using the contact information provided on the Chrome Web Store listing.
